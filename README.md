# 물품이음 전면 개선안 시안

> **v2 디자인:** 겉은 사진 먼저(방향 1), 일은 보드(방향 2), 말은 다정하게(방향 3). 비교는 `directions.html`.

[물품이음](https://github.com/h19h29-design/trade)의 디자인 전면 개선안을 실제처럼 눌러 볼 수 있게 만든 시안 사이트입니다. 설치 없이 브라우저에서 열립니다.

- **시안 열기:** `index.html` (GitHub Pages를 켜면 `https://<계정>.github.io/mulpum-ieum-prototype/`)
- **시연용 한 파일:** `demo.html` (CSS·JS·로고를 모두 담은 HTML 하나. 내려받아 더블클릭하면 열림. `python3 build-single.py`로 다시 만듦)
- **디자인 방향 비교:** `directions.html` (같은 화면을 「물건이 주인공 · 업무 보드 · 따뜻한 학교」 세 방향으로)
- **처음 보는 사람용 설명서:** `understand.html` (물품관리 용어·흐름·등장인물·규칙)
- **개선안 문서:** `proposal.html` (진단 · 원칙 · 메뉴 구조 · 진행 표시 · 디자인 기준 · 일정)

> 모든 기관·물품·사람은 가상 데이터입니다. 실제 행정처리가 아닙니다. 입력한 내용은 보는 사람의 브라우저에만 저장됩니다.

## 눌러 볼 수 있는 것

| 화면 | 해 볼 것 |
|---|---|
| 로그인 | 시연 계정 고르기 (김새빛 물품 담당자 / 박검토 업무 검토자) |
| 홈 | 오늘 할 일(내 차례만 셈), 우리 물품 진행 막대, 이웃 기관 새 물품 |
| 물품 찾기 | 검색, 분류 칩(건수), 양호만·10개 이상·관심물품, 가까운 순 정렬, 하트 |
| 물품 상세 | 상태 고르기, 수량, 예상 배송비, 받기 신청 (휴대폰은 아래 고정 버튼) |
| 우리 기관 보드 | 작성·검토 / 나눔 중 / 신청·배정 / 인계·인수 / 끝남 칸, 「내 차례만」, 보내는 것·받는 것 |
| 물품 올리기 | 입구 3개(사진·에듀파인 엑셀·대장) → 단계 5개, AI 제안 「넣기」 |
| 주고받기 한 건 | 배정 → 인계 → 인수(수량 불일치) → 대장 반영 |
| 도움말 「?」 | 화면마다 맞는 질문 |
| 더보기 | 계정 바꾸기, 시연 데이터 처음으로 |

### 시연 안내 칸

화면 왼쪽 아래 「시연 안내」 칸이 8단계 시연 순서를 따라가게 해 줍니다. 「다음」을 누르면 그 단계 화면으로 이동하고, 첫 단계 「시연 시작」은 시연 데이터를 처음 상태로 맞춥니다. ✕로 접을 수 있습니다.

### 추천 순서 (5분)

1. 김새빛으로 들어가 홈 → 「주고받기 · 내 차례」 → 한결도서관 신청 1건 예비 배정
2. 물품 찾기 → 이동식 화이트보드 → 2개 받기 신청
3. 물품 올리기 → 사진 → AI 제안 넣기 → 수량 → 증빙 3가지 체크 → 검토 요청
4. 더보기 → 박검토로 바꾸기 → 홈 「검토해 주세요」 → 게시
